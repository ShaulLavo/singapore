## Core entry points

`@singapore-editor/core/editor` exposes the editor constructor and options. `/document` covers document sessions and snapshots. `/extensions` covers plugin contributions. `/rendering`, `/syntax` and `/keymap` expose those integration contracts. `/shiki` supplies Shiki highlighting and theme conversion. `/testing` provides testing helpers. The reference also documents other exported public declaration entry points.

## Stylesheets

Stylesheets load with the modules that use them, through any bundler that handles CSS imports. The editor, gutters, find, minimap, diff, Markdown, scope lines and panes each also export `style.css` for pages that link stylesheets themselves.

## Status

The editable core, worker syntax, language-server integrations, framework adapters and read-only paged viewer exist today. The `collab` package contains a host-ordered text core; full collaborative editor and network integration remain separate planned work. Vim mode, multibuffers and editable paging remain plans.

Open an issue or pull request in the [Singapore repository](https://github.com/ShaulLavo/singapore) for planned work and contributions.
